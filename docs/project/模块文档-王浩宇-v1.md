## 三、关键设计

1. **投票一人一票**：服务层 `HasRespondedAsync` 前置校验（重复投返回业务错误）＋ DB 复合主键 `(Vote_ID, Student_ID)` 最终兜底；统计按 `Choice` 枚举聚合（同意/不同意）。
2. **投票成员校验（IT-C8-002 通过判定②）**：`IsRoomMemberAsync` 判断学生是否为投票房间在住成员（D_Bed_Allocation 中 `CheckOut_Date IS NULL`）。**发起投票**与**参与投票**双入口均校验：非本房间学生 403。
3. **Oracle 兼容（四审真机整改）**：`AnyAsync` 被 EF 翻译为 `CASE WHEN EXISTS(...) THEN True ELSE False`，Oracle 21c 无布尔字面量 → `ORA-00904`。`HasRespondedAsync` / `IsRoomMemberAsync` 统一改用 `CountAsync(...) > 0`（翻译为 `COUNT(*)`）。
4. **访客授权状态机**：`有效 → 已撤销`（撤销仅允许从「有效」发起）；「已过期」由公共服务调度（SVC-SCHED-06）定时置位，本模块不自行判过期。授权 Token 生成 `VSR_` + 12 位 GUID 大写。
5. **访客授权前置校验**：`Room_ID` 为 NOT NULL，`ApplyAsync` 只读查询当前学生活跃房间，无在住房间拒绝申请；截止时间须晚于当前时间。
6. **快递取件状态机**：取件写入 `Pickup_Time`（未取→已取）；已取件再取返回 400；归属校验（他人快递 403）。
7. **归属校验**：投票（发起人/投票人按当前 JWT 学生 ID）、访客（查看/撤销仅本人）、快递（取件仅本人）三处均做「操作他人资源 403」，与刘润东 WalletController.ResolveStudentId 同范式。
8. **跨模块红线**：审计留痕走审计公共服务；访客过期依赖兰皓衍 `POST /internal/scheduler/visitor-expire`（SVC-SCHED-06）；快递未取件联动退宿校验归刘润东（IT-C8-003 / IT-C2-004）。

## 四、数据库变更（迁移 024）

- 序列：`SEQ_D_ROOM_VOTE_ID` / `SEQ_D_VISITOR_AUTHORIZATION_ID` / `SEQ_D_PARCEL_RECORD_ID`（三张表主键，`WHEN NEW IS NULL` 模式）
- 复合主键：`D_Room_Vote_Response (Vote_ID, Student_ID)`——一人一票兜底
- 编号：安全社区迁移由 019/022 最终定稿为 **024**（避让资产/分摊域编号冲突）
