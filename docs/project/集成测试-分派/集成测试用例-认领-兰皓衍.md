## 0. 契约口径（判定标准的地基）

| 项 | 约定 |
|---|---|
| 统一响应 | `{ code, message, data }`；**code=0/200 成功**，非 0 为业务错误码 |
| 分页 | 参数 `page/pageSize`，返回 `{ items, total, page, pageSize }` |
| 鉴权 | 登录 `POST /auth/login` 拿 token，后续接口带 `Authorization: Bearer <token>` |
| 幂等 | **`Idempotency-Key` 请求头**（契约显式标注）：STU-05 缴费、STU-07 充值、STU-25 借用、DORM-29 耗材出库；内部扣分幂等用 **eventKey**（SVC-CREDIT-01） |
| data 未展开 | 多数 POST 的 `data` 契约未定义 → **成功以 code=0/200 判定，业务结果用后续 GET + DB 断言验证** |

**测试数据预留**（同一开发库，避免撞车）：

| 资源 | 预留值 |
|---|---|
| 学生 studentId | IT_STU_001、IT_STU_002…（申诉用 IT_STU_006 等新开） |
| 通知 | 通过退宿/派单/扣分等事件给 IT_STU_001 生成 ≥3 条（IT-C7-001） |
