## 0. 测试范围与目标

**集成测试要验证的"缝"**（每条链路都穿越 ≥2 个模块/认领人）：

1. 前端 → 后端：走 `/api`，JWT 鉴权贯穿。
2. 后端模块 → 公共服务：通知中心 / 信用分 / 文件存储 / 调度（Quartz）。
3. 后端模块 ↔ 后端模块：如退宿清算依赖缴费分摊、报修依赖房间资产、损坏资产转报修。
4. 后端 → Oracle：状态机合法转移、事务、约束、幂等。

**不在范围**：单元测试（组员自测）、性能压测（8/15 徐亦尘抽测）、UI 走查（8/15 阿曼卓勒）。

**验收口径**：每条用例有「预期结果（含 DB 断言）」；通过/失败可判定；失败自动进 bug 清单。
