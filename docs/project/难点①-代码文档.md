## 一、架构概览

```
Quartz 每月1日 0:00
    │
    ▼
FeeSharingJob.Execute()
    │  调用
    ▼
FeeSharingService.CalcMonthlyFee("2026-08")
    │  调用 Oracle 存储过程
    ▼
SP_Calc_Monthly_Fee('2026-08')
    │  读取 D_Utility_Fee + D_Bed_Allocation
    │  写入 D_Fee_Detail（每人一条）
    ▼
D_Fee_Detail（个人分摊明细表）
    │  被后续难点查询
    ├── 难点② BillingService.TryAutoDeduct()
    └── 难点⑥ CheckOutService.ValidateCheckout()
```

退宿时：

```
CheckOutService.ExecuteCheckout()
    │  调用
    ▼
FeeSharingService.CalcCheckoutFee("S001", 1)
    │  调用 Oracle 存储过程
    ▼
SP_Calc_Checkout_Fee('S001', 1)
    │  当月按天折算，写入 D_Fee_Detail（Bill_Type='退宿'）
    ▼
D_Fee_Detail
```

## 二、数据库层

### 2.1 依赖的表

| 表 | 角色 | 关键字段 |
|---|---|---|
| D_Utility_Fee | 读取 | Fee_ID, Room_ID, Year_Month, Water_Fee, Power_Fee, Publish_Status |
| D_Bed_Allocation | 读取 | Allocation_ID, Student_ID, Room_ID, Bed_No, CheckIn_Date, CheckOut_Date |
| D_Fee_Detail | 写入 | 见下方完整 DDL |

### 2.2 D_Fee_Detail 表结构

来自 `database/ddl/extensions/010_extension_tables.sql`，关键约束：

- `CK_D_FEE_DETAIL_TYPE`：Bill_Type IN ('月度', '退宿')
- `CK_D_FEE_DETAIL_AMOUNT`：Water_Share ≥ 0 AND Power_Share ≥ 0
- `CK_D_FEE_DETAIL_DAYS`：Stay_Days > 0 AND Total_Days > 0 AND Stay_Days ≤ Total_Days
- `UK_D_FEE_DETAIL`：UNIQUE (Fee_ID, Student_ID, Bill_Type) — 同一学生同一账单不可重复分摊

### 2.3 存储过程：SP_Calc_Monthly_Fee

**文件**：`database/sp/sp_fee_sharing.sql`

**功能**：遍历当月所有已发布的房间账单，按人天数比例生成个人分摊明细。

**参数**：

| 参数 | 类型 | 说明 |
|---|---|---|
| p_YearMonth | VARCHAR2 | 账单月份，格式 'YYYY-MM'（如 '2026-08'） |

**调用方式**：

```sql
BEGIN SP_Calc_Monthly_Fee('2026-08'); END;
```

**核心算法**：

```
总人天数 = Σ(每个在住学生的当月入住天数)
单人天数 = LEAST(月末, NVL(退宿日, 月末)) - GREATEST(月初, 入住日) + 1
某人应付水费 = 房间水费总额 × (该人天数 ÷ 总人天数)
某人应付电费 = 房间电费总额 × (该人天数 ÷ 总人天数)
```

**处理流程**：

1. 根据 p_YearMonth 计算月初 (v_MonthStart) 和月末 (v_MonthEnd)
2. 取 D_Fee_Detail 当前最大 Detail_ID，+1 作为起始主键值
3. 遍历当月所有 D_Utility_Fee 账单（外循环）
4. 对每个房间，从 D_Bed_Allocation 计算总人天数（v_TotalDays）
5. 跳过总人天数为 0 的房间
6. 对每个在住学生（内循环），计算个人天数 → 按比例算出 Water_Share 和 Power_Share → INSERT
7. COMMIT

**尾差处理**：使用 `ROUND(..., 2)` 四舍五入，所有个人分摊之和极接近房间总额（最大尾差 ±0.02 元）。

### 2.4 存储过程：SP_Calc_Checkout_Fee

**功能**：退宿时调用，为退宿学生结算当月水电分摊。

**参数**：

| 参数 | 类型 | 说明 |
|---|---|---|
| p_Student_ID | VARCHAR2 | 退宿学生学号 |
| p_Allocation_ID | NUMBER | 住宿分配记录 ID |

**调用方式**：

```sql
BEGIN SP_Calc_Checkout_Fee('S001', 1); END;
```

**与月度分摊的区别**：

| | 月度分摊 | 退宿结算 |
|---|---|---|
| 月份来源 | 参数传入 | SYSDATE 当月 |
| 入住天数 | 月初至月末 | 月初至今天 |
| Bill_Type | '月度' | '退宿' |
| 影响范围 | 所有房间全部学生 | 仅退宿学生一人 |

## 三、C# 服务层

### 3.1 数据模型

**文件**：`backend/Models/FeeDetail.cs`

```csharp
[Table("D_Fee_Detail", Schema = "DORM_OPER")]
public class FeeDetail
{
    [Key] [Column("Detail_ID")] public int DetailId { get; set; }
    [Column("Fee_ID")] public int FeeId { get; set; }
    [Column("Student_ID")] public string StudentId { get; set; }
    [Column("Room_ID")] public int RoomId { get; set; }
    [Column("Water_Share")] public decimal WaterShare { get; set; }
    [Column("Power_Share")] public decimal PowerShare { get; set; }
    [Column("Stay_Days")] public int StayDays { get; set; }
    [Column("Total_Days")] public int TotalDays { get; set; }
    [Column("Bill_Type")] public string BillType { get; set; }
    [Column("Is_Paid")] public string IsPaid { get; set; }
    [Column("Create_Time")] public DateTime CreateTime { get; set; }
}
```

- 使用 `decimal`（非 `double`）存储金额，保证精度
- `[Key]` 标记主键，`[Column]` 映射 Oracle 大写列名
- `[Table]` 指定 Schema = DORM_OPER

### 3.2 服务接口

**文件**：`backend/Services/IFeeSharingService.cs`

```csharp
public interface IFeeSharingService
{
    Task CalcMonthlyFee(string yearMonth);
    Task CalcCheckoutFee(string studentId, int allocationId);
    Task<List<FeeDetail>> GetFeeDetail(string studentId, string yearMonth);
}
```

### 3.3 服务实现

**文件**：`backend/Services/FeeSharingService.cs`

**依赖注入**：构造函数接收 `AppDbContext`。

**CalcMonthlyFee**：调用原生 SQL `BEGIN SP_Calc_Monthly_Fee({0}); END;`，参数化防注入。

**CalcCheckoutFee**：调用原生 SQL `BEGIN SP_Calc_Checkout_Fee({0}, {1}); END;`。

**GetFeeDetail**：使用 `FromSqlRaw` 执行原生 SELECT，按 Student_ID + Create_Time 所在月份过滤。绕过 EF Core 的 LINQ 翻译（因 DbContext 模型尚未完全与 DDL 对齐）。

## 五、定时任务

**文件**：`backend/Jobs/FeeSharingJob.cs`

**实现**：`IJob` 接口，构造函数注入 `IFeeSharingService`。

**执行逻辑**：
1. 取当前时间 `DateTime.Now.ToString("yyyy-MM")`
2. 调用 `_service.CalcMonthlyFee(yearMonth)`

**cron 表达式**：`0 0 0 1 * ?` → 每月 1 日 0:00:00

## 六、注册与配置

### 6.1 Program.cs

```csharp
// 第 43 行：注册服务
builder.Services.AddScoped<IFeeSharingService, FeeSharingService>();

// 第 46-57 行：注册 Quartz
builder.Services.AddQuartz(q =>
{
    var jobKey = new JobKey("FeeSharingJob");
    q.AddJob<FeeSharingJob>(opts => opts.WithIdentity(jobKey));
    q.AddTrigger(opts => opts
        .ForJob(jobKey)
        .WithIdentity("FeeSharingTrigger")
        .WithCronSchedule("0 0 0 1 * ?"));
});
builder.Services.AddQuartzHostedService(q => q.WaitForJobsToComplete = true);
```
