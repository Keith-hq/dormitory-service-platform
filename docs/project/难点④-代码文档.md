## 一、架构概览

### 业务流程

```
学生端（STU-24~27）
  │
  ├─ GET /api/shared-items        → 查询可借物品（状态=正常 + 库存>0）
  ├─ POST /api/shared-items/{id}/borrow
  │     → SP_Borrow_Item  → 信用分≥60？→ 原子扣库存(Available_Qty-1) → 写借出记录(期24h)
  │     → 返回 (rc, loanId)
  │
  ├─ POST /api/item-loans/{id}/return
  │     → SP_Return_Item → 库存+1 → 写归还时间 → 超期？→ 扣信用分(每天5分)
  │
  └─ GET /api/item-loans          → 查询本人借还记录

宿管端（DORM-29~30）
  │
  ├─ GET /api/repair-materials     → 查询耗材库存
  └─ POST /api/repair-materials/{id}/consume
        → SP_Consume_Material → 原子扣库存(Stock_Qty-n) → 写消耗记录

定时任务
  └─ 每15分钟: SP_Check_Overdue → 扫逾期未归还 → 扣信用分(每天5分)
```

### 并发保护（乐观锁 + 幂等）

| 层 | 机制 | 说明 |
|---|---|---|
| 借出 | `UPDATE WHERE Available_Qty > 0` + `SQL%ROWCOUNT` | 原子扣减，无需显式加锁 |
| 消耗 | `UPDATE WHERE Stock_Qty >= p_Quantity` + `SQL%ROWCOUNT` | 同上，支持批量扣减 |
| 归还 | `SELECT WHERE Return_Time IS NULL` 前置检查 | 同一 Loan_ID 只能归还一次 |
| 逾期巡检 | INSERT 前置 + `DUP_VAL_ON_INDEX` 捕获 | Event_Key 按 Loan_ID + 日期去重，同日不重复扣分 |
| 序列 | `SEQ_CREDIT_LOG`、`SEQ_ITEM_LOAN`、`SEQ_MATERIAL_USAGE` | 独立序列，不跨模块复用 |

### 事务边界

```
共享物品库存（D_Shared_Item.Available_Qty）← 李昂（难点④ SP_Borrow_Item / SP_Return_Item）
共享物品主数据（D_Shared_Item.* 增删改）    ← 刘鸿铭（DORM-48/49）
                                          两者通过 SP 接口隔离，不直改对方数据
```

### 2.3 存储过程：SP_Borrow_Item

**文件**：`database/sp/sp_shared_item.sql`

**功能**：信用分检查通过后，原子扣减共享物品库存并创建借出记录。

**参数**：

| 参数 | 类型 | 说明 |
|---|---|---|
| p_Item_ID | NUMBER | 共享物品 ID |
| p_Student_ID | VARCHAR2 | 借出学生学号 |
| p_Result_Code | OUT NUMBER | 0=成功, 1=物品不存在, 2=物品停用, 3=库存不足, 4=信用分冻结 |
| p_Loan_ID | OUT NUMBER | 借出记录 ID（仅在 rc=0 时有效） |

**调用方式**：

```sql
DECLARE rc NUMBER; lid NUMBER;
BEGIN SP_Borrow_Item(1, 'S001', rc, lid); DBMS_OUTPUT.PUT_LINE('rc=' || rc || ' loan=' || lid); END;
```

**处理流程**：

1. Fail-fast 校验：物品存在？→ 状态=正常？→ 库存 > 0？→ 信用分 ≥ 60？
2. 原子扣减：`UPDATE D_Shared_Item SET Available_Qty = Available_Qty - 1 WHERE Item_ID = p_Item_ID AND Available_Qty > 0`
3. `SQL%ROWCOUNT = 0` → 并发冲突，返回 rc=3
4. `INSERT D_Item_Loan`（Due_Time = SYSDATE + 1，24 小时后到期），`RETURNING Loan_ID INTO p_Loan_ID`
5. COMMIT

**信用分阈值**：Current_Score < 60 → 冻结，拒绝借出。阈值对齐 `D_Credit_Account` 的冻结线。

### 2.4 存储过程：SP_Return_Item

**功能**：归还共享物品，自动计算超期天数并扣信用分。

**参数**：

| 参数 | 类型 | 说明 |
|---|---|---|
| p_Loan_ID | NUMBER | 借出记录 ID |
| p_Result_Code | OUT NUMBER | 0=成功, 1=借出记录不存在或已归还 |

**处理流程**：

1. `SELECT WHERE Loan_ID = p_Loan_ID AND Return_Time IS NULL` — 确保未归还，同时取 Item_ID、Student_ID、Due_Time
2. 库存回加：`UPDATE D_Shared_Item SET Available_Qty = Available_Qty + 1`
3. 写归还时间：`UPDATE D_Item_Loan SET Return_Time = SYSDATE`
4. 超期判定：`IF SYSDATE > Due_Time` → `v_Overdue_Days = TRUNC(SYSDATE - Due_Time)`
5. 扣分：`v_Penalty = LEAST(v_Score, v_Overdue_Days * 5)`，每超 1 天扣 5 分，不超过当前分数
6. 写信用流水：`INSERT D_Credit_Log`（Event_Key = `'OVERDUE-' || Loan_ID`，归还不重复）
7. COMMIT

### 2.5 存储过程：SP_Consume_Material

**功能**：维修耗材出库，原子扣减库存并记录消耗。

**参数**：

| 参数 | 类型 | 说明 |
|---|---|---|
| p_Material_ID | NUMBER | 耗材 ID |
| p_Ticket_ID | NUMBER | 关联报修工单 ID |
| p_Quantity | NUMBER | 消耗数量 |
| p_Result_Code | OUT NUMBER | 0=成功, 1=耗材不存在, 2=库存不足 |

**处理流程**：

1. 乐观扣减：`UPDATE D_Repair_Material SET Stock_Qty = Stock_Qty - p_Quantity WHERE Material_ID = p_Material_ID AND Stock_Qty >= p_Quantity`
2. `SQL%ROWCOUNT = 0` → 回查原因（SELECT 区分"不存在"和"不够"），返回对应 rc
3. INSERT D_Repair_Material_Usage 消耗记录
4. COMMIT

### 2.6 存储过程：SP_Check_Overdue

**功能**：定期扫描所有逾期未归还的借出记录，按天扣信用分。每次巡检同一天同一笔 Loan_ID 只扣一次（Event_Key 幂等）。

**调用方式**：

```sql
BEGIN SP_Check_Overdue; END;
```

**处理流程**：

1. 游标遍历 `WHERE Return_Time IS NULL AND Due_Time < SYSDATE`
2. 计算扣分额度：`v_Penalty = LEAST(5 * Overdue_Days, 100)`（单次上限 100 分）
3. **INSERT 在前**：先写日志（Event_Key 含 Loan_ID + 日期），再 UPDATE 信用分
4. `DUP_VAL_ON_INDEX` → 今天已处理过，整块跳过（含 UPDATE）
5. COMMIT

```csharp
public interface IInventoryTxnService
{
    Task<(int resultCode, int loanId)> BorrowItem(int itemId, string studentId);
    Task<int> ReturnItem(int loanId);
    Task<int> ConsumeMaterial(int materialId, int ticketId, int quantity);
    Task CheckOverdue();
    Task<List<SharedItem>> GetSharedItems(int? buildingId = null);
    Task<List<ItemLoan>> GetItemLoans(string studentId);
    Task<List<RepairMaterial>> GetRepairMaterials();
}
```

### 3.3 服务实现

**文件**：`backend/Services/InventoryTxnService.cs`

**写操作**：OUT 参数存储过程使用原生 `OracleCommand` 调用（`CommandType.StoredProcedure`），处理 `OracleDecimal` → `int` 类型转换。

- `BorrowItem`：返回 `(rc, loanId)` 元组，参考 `FacilityBookingService.BookFacility` 模式
- `ReturnItem` / `ConsumeMaterial`：返回 rc，参考 `StartUse` / `FinishUse` 模式
- `CheckOverdue`：无 OUT 参数，使用 `ExecuteSqlRawAsync("BEGIN SP_Check_Overdue; END;")`

**查询操作**：使用 `FromSqlRaw` 显式 SQL，将 Oracle 大写列名通过别名映射到 C# 驼峰属性。

```csharp
// 例：SELECT Item_ID AS ItemId, Item_Name AS ItemName FROM D_Shared_Item
```

## 六、注册与配置

### 6.1 Program.cs

```csharp
// 第 83 行：注册服务
builder.Services.AddScoped<IInventoryTxnService, InventoryTxnService>();

// Quartz 块中注册逾期巡检 Job
var overdueKey = new JobKey("OverdueCheckJob");
q.AddJob<OverdueCheckJob>(opts => opts.WithIdentity(overdueKey));
q.AddTrigger(opts => opts.ForJob(overdueKey).WithIdentity("OverdueCheckTrigger")
    .WithCronSchedule("0 0/15 * * * ?", x => x.InTimeZone(tz)));
```
