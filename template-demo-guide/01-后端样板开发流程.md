# 01 — 后端样板开发流程

> C# 三层架构 + EF Core 对接 Oracle 26AI 规范

---

## 一、前置依赖

| 依赖项 | 版本/说明 |
|---|---|
| .NET SDK | .NET 8.0 |
| IDE | Visual Studio 2022 / Rider / VS Code |
| Oracle 数据库 | Oracle 26AI（容器 `dorm-oracle-db`） |
| NuGet 包 | `Oracle.EntityFrameworkCore`、`Oracle.ManagedDataAccess.Core` |
| 数据库账号 | `DORM_OPER` / `Dorm@2026`（拥有 DBA 权限） |
| Docker 环境 | Oracle 容器已启动，端口 1521 可访问 |

> 首次使用请先执行 [ops-local-oracle](../ops-local-oracle/) 中的 `docker compose up -d` 启动 Oracle 容器。

## 二、分步操作

### 2.1 创建 ASP.NET Core Web API 项目

```bash
dotnet new webapi -n TemplateDormApi --framework net8.0
cd TemplateDormApi
```

### 2.2 安装 Oracle EF Core 依赖包

```bash
dotnet add package Oracle.EntityFrameworkCore
dotnet add package Oracle.ManagedDataAccess.Core
```

### 2.3 搭建三层目录结构

```
TemplateDormApi/
├── Controllers/   // 接收前端 HTTP 请求
├── Services/      // 业务逻辑层
├── Repository/    // 数据库交互层（基础 CRUD 基类）
├── Models/        // Oracle 实体映射类
├── DTO/           // 接口入参 / 出参实体
├── Data/          // EF Core DbContext
```

### 2.4 配置 EF Core 连接 Oracle

**方式一：User Secrets（推荐，禁止硬编码）**

```bash
dotnet user-secrets init
dotnet user-secrets set "OracleConnection" "Data Source=localhost:1521/DORMPDB;User Id=DORM_OPER;Password=Dorm@2026;"
```

**方式二：appsettings.Development.json**

```json
{
  "ConnectionStrings": {
    "OracleConnection": "Data Source=localhost:1521/DORMPDB;User Id=DORM_OPER;Password=Dorm@2026;"
  }
}
```

### 2.5 创建 DbContext

在 `Data/AppDbContext.cs` 中绑定 Oracle 实体：

```csharp
public class AppDbContext : DbContext
{
    public AppDbContext(DbContextOptions<AppDbContext> options) : base(options) { }

    public DbSet<Building> Buildings => Set<Building>();
    public DbSet<Room> Rooms => Set<Room>();
    public DbSet<Asset> Assets => Set<Asset>();

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<Building>().ToTable("BUILDINGS");
        modelBuilder.Entity<Room>().ToTable("ROOMS");
        modelBuilder.Entity<Asset>().ToTable("ASSETS");
    }
}
```

### 2.6 注册 DbContext（Program.cs）

```csharp
builder.Services.AddDbContext<AppDbContext>(options =>
    options.UseOracle(builder.Configuration.GetConnectionString("OracleConnection")));
```

## 三、代码模板

### 3.1 统一返回格式

```csharp
public class ApiResponse<T>
{
    public int Code { get; set; } = 200;
    public string Message { get; set; } = "操作成功";
    public T? Data { get; set; }
}

public static class ApiResponse
{
    public static ApiResponse<T> Ok<T>(T data, string msg = "操作成功")
        => new() { Code = 200, Message = msg, Data = data };

    public static ApiResponse<object> Error(int code, string msg)
        => new() { Code = code, Message = msg };
}
```

### 3.2 通用 Repository 基类

```csharp
public interface IBaseRepository<T> where T : class
{
    Task<List<T>> GetAllAsync();
    Task<T?> GetByIdAsync(int id);
    Task<T> AddAsync(T entity);
    Task<T> UpdateAsync(T entity);
    Task DeleteAsync(int id);
    Task<(List<T> Items, int Total)> GetPagedAsync(int page, int pageSize);
}

public class BaseRepository<T> : IBaseRepository<T> where T : class
{
    protected readonly AppDbContext _context;
    protected readonly DbSet<T> _dbSet;

    public BaseRepository(AppDbContext context)
    {
        _context = context;
        _dbSet = context.Set<T>();
    }

    public virtual async Task<List<T>> GetAllAsync() => await _dbSet.ToListAsync();

    public virtual async Task<T?> GetByIdAsync(int id) => await _dbSet.FindAsync(id);

    public virtual async Task<T> AddAsync(T entity)
    {
        await _dbSet.AddAsync(entity);
        await _context.SaveChangesAsync();
        return entity;
    }

    public virtual async Task<T> UpdateAsync(T entity)
    {
        _dbSet.Update(entity);
        await _context.SaveChangesAsync();
        return entity;
    }

    public virtual async Task DeleteAsync(int id)
    {
        var entity = await GetByIdAsync(id);
        if (entity != null)
        {
            _dbSet.Remove(entity);
            await _context.SaveChangesAsync();
        }
    }

    public virtual async Task<(List<T> Items, int Total)> GetPagedAsync(int page, int pageSize)
    {
        var total = await _dbSet.CountAsync();
        var items = await _dbSet.Skip((page - 1) * pageSize).Take(pageSize).ToListAsync();
        return (items, total);
    }
}
```

### 3.4 Controller 模板

```csharp
[ApiController]
[Route("api/[controller]")]
public class BuildingController : ControllerBase
{
    private readonly IBuildingService _service;

    public BuildingController(IBuildingService service)
    {
        _service = service;
    }

    [HttpGet]
    public async Task<ActionResult<ApiResponse<object>>> GetPaged(
        [FromQuery] int page = 1,
        [FromQuery] int pageSize = 10)
    {
        var result = await _service.GetPagedAsync(page, pageSize);
        return Ok(ApiResponse.Ok(result));
    }

    [HttpPost]
    public async Task<ActionResult<ApiResponse<Building>>> Create([FromBody] BuildingDto dto)
    {
        var entity = await _service.AddAsync(dto);
        return Ok(ApiResponse.Ok(entity));
    }
}
```

## 四、验收标准

| 检查项 | 标准 |
|---|---|
| 项目启动 | `dotnet run` 无报错，Swagger 页面可访问 |
| 数据库连接 | EF Core 能正常读取 `BUILDINGS` 表数据 |
| 三层架构 | Controller → Service → Repository 调用链完整 |
| 统一返回格式 | 所有接口返回 `{ code, message, data }` |
| 依赖注入 | `Program.cs` 正确注册 DbContext、Service、Repository |
| 无硬编码密码 | 连接字符串配置在 User Secrets 中 |

## 五、常见报错

| 报错信息 | 原因 | 解决方案 |
|---|---|---|
| `ORA-12154: TNS could not resolve` | 连接字符串错误 | 检查 Service Name 是否为 `DORMPDB` |
| `ORA-01017: invalid username/password` | 账号密码错误 | 确认 `DORM_OPER` 密码为 `Dorm@2026` |
| `ORA-00942: table or view does not exist` | 表未创建 | 联系架构师执行 DDL，确认表已在 DORMPDB 中 |
| `The type initializer for 'Oracle.ManagedDataAccess.Client.OracleConnection' threw an exception` | 缺少 Oracle 运行时依赖 | 确认已安装 `Oracle.ManagedDataAccess.Core` NuGet 包 |
| `Cannot scaffold the connection string` | User Secrets 未配置 | 执行 `dotnet user-secrets set` |
| `Object reference not set to an instance` | 依赖注入未注册 | 检查 `Program.cs` 中的 `AddScoped` / `AddDbContext` 注册 |
