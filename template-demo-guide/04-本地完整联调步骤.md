# 04 — 本地完整联调步骤

> 数据库 → 后端 → 接口 → 前端 全链路联调流程

---

## 一、前置依赖

| 依赖项 | 说明 |
|---|---|
| Oracle 容器 | `dorm-oracle-db` 已启动，PDB `DORMPDB` 就绪 |
| 数据表 | 初始化脚本完成后，由 `DORM_OPER` 按授权读写 |
| 后端项目 | `TemplateDormApi` 编译通过，Swagger 可访问 |
| 前端项目 | `template-frontend` 启动成功，代理配置生效 |
| Apifox | 接口契约已录入，Mock 数据可用 |
| DBeaver | 数据库连接工具，用于验证数据变更 |

---

## 二、分步操作

### 第一阶段：启动 Oracle 数据库

```bash
# 1. 进入 Oracle 配置目录
cd deploy/oracle

# 2. 创建本地配置（首次使用）
copy .env.example .env
# 编辑 .env，填写 ORACLE_PASSWORD

# 3. 启动容器
docker compose up -d

# 4. 查看初始化日志（等待 PDB 就绪）
docker logs -f dorm-oracle-db

# 5. 看到以下日志代表就绪
# Pluggable database DORMPDB opened read write
```

### 第二阶段：验证数据库连接

1. 打开 DBeaver
2. 连接参数：`localhost:1521` / Service Name `DORMPDB` / 用户名和密码以本机初始化配置为准
3. 执行查询验证表数据：`SELECT * FROM BUILDINGS;`

### 第三阶段：启动后端服务

```bash
cd template-backend
dotnet restore
dotnet run
```

验证：
- 浏览器访问 `http://localhost:5000/swagger`
- 展开 `GET /api/building` → 点击 "Try it out" → 执行
- 确认返回数据与 DBeaver 中 `BUILDINGS` 表一致

### 第四阶段：Apifox 接口契约验证

1. 打开 Apifox → 选择项目
2. 进入"样板间 - 楼栋资产"分组
3. 逐个调用 CRUD 接口，确认响应格式与后端一致
4. 如有差异 → 更新 Apifox 或后端代码 → 重新对齐

### 第五阶段：启动前端

```bash
cd template-frontend
npm install
npm run dev
```

验证：
- 浏览器访问 `http://localhost:3000`
- 进入 `/building` 页面
- 确认列表数据正常展示

### 第六阶段：全链路联调（核心验收动作）

**测试用例 1：新增楼栋**

| 步骤 | 操作 | 验收 |
|---|---|---|
| 1 | 在前端页面点击"新增"，填写楼栋信息 | 弹窗正常，表单可输入 |
| 2 | 点击提交 | 列表自动刷新，显示新增记录 |
| 3 | DBeaver 查询 `BUILDINGS` 表 | 新记录已写入 |
| 4 | 查看后端控制台日志 | EF Core SQL 日志输出 |

**测试用例 2：修改房间**

| 步骤 | 操作 | 验收 |
|---|---|---|
| 1 | 在前端列表点击"编辑" | 表单正确回显已有数据 |
| 2 | 修改字段值，提交 | 列表自动刷新 |
| 3 | DBeaver 查询 | 字段更新为修改后的值 |

**测试用例 3：删除资产**

| 步骤 | 操作 | 验收 |
|---|---|---|
| 1 | 在前端列表点击"删除" | 弹出确认对话框 |
| 2 | 确认删除 | 列表自动刷新，该记录消失 |
| 3 | DBeaver 查询 | 记录已删除（软删除则状态变更） |

## 五、常见报错

| 报错信息 | 原因 | 解决方案 |
|---|---|---|
| `Connection refused (localhost:1521)` | Oracle 容器未启动 | `docker compose up -d` 启动容器 |
| `ORA-00942: table does not exist` | DDL 未执行 | 联系架构师执行建表脚本 |
| `500 Internal Server Error` | 后端权限或配置错误 | 查看后端控制台异常堆栈 |
| `Network Error` 前端调用后端 | 代理或 CORS 配置错误 | 检查 `vite.config.js` 代理设置 |
| `docker compose up` 失败 | 端口已被占用 | `netstat -an | grep 1521` 排查 |
| EF Core 查询返回空 | 表已创建但无数据 | 在 DBeaver 手动插入测试数据 |
